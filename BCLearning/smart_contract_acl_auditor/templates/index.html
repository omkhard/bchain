▶ What is Access Control?

Access control answers: "Who is allowed to call this function?" In Solidity, every function is callable by anyone unless restricted. Forgetting to add a modifier means any attacker on the internet can call it.

// ❌ Anyone can call this — no restriction
function withdraw(uint amount) external {
    payable(msg.sender).transfer(amount);
}
// ✅ Only the owner can call this
function withdraw(uint amount) external onlyOwner {
    payable(msg.sender).transfer(amount);
}
▶ The Parity Wallet Hack ($30M)

In 2017, Parity's multisig wallet library had an unprotected initWallet() function. An attacker called it on the deployed library, became the owner, then called kill() to destroy it — permanently freezing $150M in dependent wallets.

// ❌ PARITY BUG — anyone can reinitialize
function initWallet(address[] _owners) public {
    owner = _owners[0]; // No protection!
}

function kill(address _to) public {
    selfdestruct(payable(_to)); // No guard!
}
Fix: Use a constructor instead of init(), or add an initialized boolean flag.
▶ tx.origin vs msg.sender

tx.origin is the original EOA that started the transaction chain. msg.sender is the immediate caller. An attacker can trick a victim into calling a malicious contract, which then calls yours — tx.origin is still the victim!

// ❌ Phishing attack possible
require(tx.origin == owner, "Not owner");
// Attacker: trick owner → call MaliciousContract → calls your contract
// tx.origin = owner ✓  ... but msg.sender = attacker contract
// ✅ Always use msg.sender
require(msg.sender == owner, "Not owner");
▶ Two-Step Ownership Transfer

Single-step transfers are dangerous: if you mistype the address, ownership is permanently lost. Two-step forces the new owner to prove they control the address.

// ❌ One typo = lost contract forever
function transferOwnership(address newOwner) external onlyOwner {
    owner = newOwner; // If newOwner is wrong, game over
}
// ✅ Two-step: new owner must accept
function transferOwnership(address newOwner) external onlyOwner {
    pendingOwner = newOwner;
}
function acceptOwnership() external {
    require(msg.sender == pendingOwner);
    owner = pendingOwner;
    pendingOwner = address(0);
}
▶ Role-Based Access Control (RBAC)

For complex protocols, a single owner is not enough. OpenZeppelin's AccessControl lets you define granular roles: MINTER_ROLE, PAUSER_ROLE, ADMIN_ROLE — each granted to different addresses.

bytes32 public constant MINTER_ROLE = keccak256("MINTER_ROLE");

function mint(address to, uint amount) external onlyRole(MINTER_ROLE) {
    _mint(to, amount);
}
// grantRole(MINTER_ROLE, someAddress) — only DEFAULT_ADMIN_ROLE
Real-world example: Compound Finance uses RBAC to separate proposers from executors in governance.
